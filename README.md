# Microgrid Energy Scheduling

数学建模项目：面向光伏、储能与外网购电协同的微网日内调度。

## 问题内容

- 确定性场景下的光伏—储能—购电调度
- 负荷与光伏波动下的风险评估
- 基于定时预测更新的滚动优化
- 实时波动电价下的策略比较

## 核心脚本

- `solve_c.py`：模型求解主流程
- `prepare_outputs.py`：结果整理与导出
- `policy_comparisons.py`：策略对比
- `make_figures.py` / `make_figures_v2.py`：图表生成
- `make_report_materials.py`：报告素材生成
